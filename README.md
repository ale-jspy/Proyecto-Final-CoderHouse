# API de Productos y Carritos -

Hola profe, un gusto, este es mi proyecto. Consiste en un servidor construido con Node.js y Express que permite gestionar productos y carritos de compra. Toda la persistencia se realiza mediante archivos JSON locales.

---

// Tecnologías utilizadas

- Node.js
- Express.js
- File System (persistencia en JSON)
- Nodemon (modo desarrollo)
